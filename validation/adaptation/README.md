# FFX 与 AD+GBn2 适配改进：案例测试

日期：2026-11-25。分支：`alphadynamics.refine`。

## 已保留的改进

修改前先提交基线 `4535b6f`。保留线搜索修复 `d36e718`，回归测试提交 `8942ee0`、`3fc816f`。

FFX 原线搜索在缩步重启时调用 `begin()`，却没有返回递归结果，可能继续使用不一致的搜索状态。修复为 `return begin()`；增加有限值检查和搜索次数上限，失败时恢复初始坐标并重新计算能量、梯度，返回失败状态。

原 71 体系批次的 **4xcr** 曾在实验项的样条/尺度拟合阶段触发线搜索递归失败；修复后可完成该阶段，进入 AD+GBn2 坐标优化并收敛。其余探索方向的最终取舍见下文；候选结果不作为默认生产结果。

## 验证设计

共选择 9 个体系：冷冻电镜 8dat、6j6j、7kzn；低分辨率 X 射线 1yab、4xcr、1u87、1m10；高分辨率 X 射线 2fma、3njw。首轮使用 5 个体系，随后加入验证案例；这是探索性案例筛选，不是独立盲测。

保持 AD+GBn2 的完整 AUX 电荷响应、ACE、单位转换、原子顺序和坐标准备不变。固定权重对照为 0.05，GRMS 阈值 1.0；通常最多 120 步，FIRE 探索最多 300 步。旧 71 体系基线最多 200 步，因此单列，不作为同预算消融。所有本轮候选均使用修复后的线搜索。

使用同一 CCTBX/AQuaRef 独立评估器评估拟合与几何。键长与键角的 `mean` 字段实际是 RMS 偏差。Rfree 越低越好、CCmask 越高越好；同时检查碰撞、MolProbity 与收敛。没有仅按 Rfree 或目标能量选择方案。AIMNet2 是已有完整流程结果，非相同优化器下的势函数消融。

## 方向取舍

|方向|实测结论|处理|
|---|---|---|
|线搜索重启返回值、有限值检查与失败恢复|4xcr 从实验项尺度拟合递归失败变为完整精修收敛；3 项回归测试通过|**保留并提交**|
|限制单原子步长、容许能量噪声的 bounded L-BFGS|8dat 碰撞减少，但 CCmask 0.73489→0.72489；4xcr Rfree 0.28541→0.29084；1u87 Rfree 0.23459→0.23760；2fma 和 3njw 仍未收敛|不保留|
|固定提高数据权重 0.05→0.2|同一 bounded 优化器下，8dat CCmask 提高，但 clashscore 6.54→116.11、键长 RMS 0.01249→0.02431 Å，且未收敛|不保留|
|分阶段提高权重 0.05→0.2|8dat clashscore 99.75，未收敛；没有解决高权重的几何代价|不保留|
|参考键长谐和约束 k=200/1000|部分案例键长与拟合同时改善；但独立约束对照中，1yab 在 GRMS≈1.126 时线搜索失败，4xcr 和 1m10 的 Rfree 变差；7kzn 的组合方案未收敛|不保留|
|FIRE 力驱动优化|3njw 第 135 步收敛，但 Rfree 0.14646，高于 AIMNet2 的 0.12118；2fma 跑满 300 步，GRMS=1.1167，未收敛；7kzn 的拟合和碰撞均不优于原优化器|不保留|

FIRE 的 300 步与其他候选的 120 步预算不同，其结果仅用于探索；不能据此宣称相同计算预算下更优。几何约束在少数体系有收益，但未通过本轮稳定性和拟合质量筛选，因此没有作为可选功能留在生产代码中。

4xcr 是本轮明确改善的案例：修复后的原优化器 Rfree=**0.28541**，已有 AIMNet2 流程为 **0.30678**；键长 RMS 分别为 **0.00952 / 0.01150 Å**，clashscore 为 **0.324 / 2.594**。该案例三项指标更好，不代表其余体系或整个 71 体系已优于 AIMNet2。

其余候选的收益没有达到“明显效果好且稳定”的保留标准。本轮生产代码只保留线搜索修复，AD+GBn2 物理目标和默认权重仍沿用已保存基线。

## 测试与审计

Slurm 24962 的 Maven 反应堆构建通过，显式启用测试（`-DskipTests=false`）。`LineSearchTest` 共 3 项，失败 0、错误 0、跳过 0：陡峭二次函数触发缩步重启后状态一致、非有限试探恢复原状态、平坦目标的搜索有界退出。候选类中的 LineSearch 与实际模块源码 SHA256 一致。

45 个生成结构全部完成独立评估，评估错误为 0；45 个结构的审计全部通过。审计通过只表示结构身份、坐标与记录有效，并不代表精修质量改善或优化收敛。49 次尝试中，35 次收敛、10 次生成结构但未收敛、3 次失败、1 次主动中止；不存在未结束的运行。该计数按候选运行统计，不是独立体系成功率。

任务 GPU 并发不超过两张。全部实验已完成；未采用的候选实现及编译产物已移出 FFX 工作树，仅保留实际采用的核心修复、测试与结果记录。未再次运行完整 71 体系，不能据此声称 71 体系总体质量已提高或普遍优于 AIMNet2。
